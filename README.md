RADXA VISION/ VitaDeck

A custom Linux gaming handheld inspired by the PSP, PS Vita and Steam Deck.

RADXA VISION is a project I'm building for Hack Club's Half-Life programme. I want to make my own handheld gaming device from scratch, combining ideas from my favourite handhelds with my own design and features.

The plan is to build something portable and comfortable to play on, with a big, high-resolution screen, proper gaming controls and Linux running underneath. I'll be designing my own PCBs, making a custom 3D model for the shell and figuring out how to get all the hardware and software working together.

Planned features
SBC: ROCK 4C+ with 4GB RAM.
Display: A high-resolution screen around 6 inches, connected through an HDMI controller board.
Custom PCBs: Designed in KiCad for the controls and internal electronics.
Controls: Two analogue sticks with L3/R3 clicks, a D-pad, four face buttons, shoulder buttons and L2/R2 triggers.
Audio: Built-in stereo speakers and a headphone jack.
Cooling: A heatsink, fan and vents to keep the device cool while gaming.
Battery: An internal rechargeable battery, with the goal of keeping the device as thin as possible.
Custom shell: Designed in Onshape, with ergonomic grips and space for all the internal components.
RGB lighting: Hopefully, some lighting around the rear logo if I can fit it into the design.
💻 Software

I'll mainly be using Debian 12 (Bookworm), but I'll also experiment with Debian 13 (Trixie) to see how newer packages, drivers and desktop environments work on the hardware.

I'll be working on getting the controls recognised properly in Linux, setting up the gaming software, improving performance and testing emulators like PPSSPP and RetroArch.

The goal

I want to learn how to bring a hardware and software project together, from designing a PCB and modelling the shell to configuring Linux and getting games running.

The PSP and PS Vita are my inspiration for the portability and controls, while the Steam Deck is a big inspiration for running a flexible Linux gaming system.

I'll use this repository to share my progress, CAD models, PCB designs, code, experiments and anything I learn along the way. I'll also document problems and changes as I figure things out.

Current status: Still in development! I'm working on the hardware design, checking component compatibility and planning how everything will fit together.
